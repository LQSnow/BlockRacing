# Legacy pacing regression fixture

`legacy-task-session-v2.yml` was exported from the actual plugin JAR built before acquisition pacing was implemented, using its original `TaskSession` class. It was not generated by the new sampler.

- Paper API: `26.3.build.244-stable`; plugin artifact version: `26.2.1`.
- Normal preset; copper extras off; 50 targets; Racing; seed `4242`.
- Frozen pool: first 80 canonical sorted entries allowed by that preset.
- Red: 17 completions, selecting the last active target; one full roll before completion 6.
- Blue: 9 completions, selecting the first active target; no roll.
- The snapshot was serialized and parsed before collecting expected continuation frames, to detach its lists from the live session.
- `expected.red` and `expected.blue` contain every later active group when completing the first active target, ending with an empty frame.

The regression requires the new implementation to preserve these exact future sequences and the old RNG behavior. New category pacing is intentionally disabled for this saved match, including after it is saved again in the new format.
