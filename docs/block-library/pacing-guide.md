# 宏观对局节奏：先发育，再探索，最后挑战

之前的实现只调整采集、加工、探索标签的概率，等级使用固定权重，因此噩梦预设开局就可能出现 T6。这次补齐等级阶段门槛和动态等级比例；维度、等级和获取方式共同控制节奏，不观察四个槽位的组合，不设置固定简单槽。

## 默认五个阶段

所有进度均为**本队已完成目标数 / 本局目标总数**，与积分、游戏时间、已生成序号无关。阈值统一为 `ceil(total * percentage / 100)`。

|阶段|进度|50 目标时的起点|可新出现的等级上限|主要体验|
|---|---|---:|---|---|
|发育|0%～不足 15%|0|T1–T2|常见资源、基础工具和合成，先建立推进能力|
|拓展|15%～不足 35%|完成 8 个|T1–T3|加入常见群系和资源探索|
|探索与加工|35%～不足 60%|完成 18 个|T1–T4|提高探索与进阶制作比重|
|进阶挑战|60%～不足 80%|完成 30 个|T1–T5|少量稀有资源、特殊采集和后期维度目标|
|收尾挑战|80% 起|完成 40 个|T1–T6|允许少量极限目标，同时保留较低等级任务|

等级上限还要与玩家选定预设取交集：休闲和简单始终不超过 T2，标准不超过各维度原有的 T4/T3，困难不出现 T6，噩梦才包含全部 T 级。不会因为到了后期就越过预设范围。

即使选择噩梦，开局四个目标也只来自主世界 T1–T2。截图中的苦力怕头是 T6，默认 50 目标时最早在完成 40 个后的补位或重抽中出现；蜂蜜块属于 T4，深层铁矿石、深层钻石矿石属于 T5，分别受 35% 和 60% 门槛限制。

## 难度比例随进度变化

预设原有的六级基础权重继续保留，实际等级权重为：

```text
预设的该等级基础权重 × 当前阶段的该等级倍率
```

|阶段开始进度|T1|T2|T3|T4|T5|T6|
|---|---:|---:|---:|---:|---:|---:|
|0%|8|3|0|0|0|0|
|15%|4|4|1|0|0|0|
|35%|2|3|4|1|0|0|
|60%|1|2|4|3|1|0|
|80%|1|1|2|4|4|2|

0 代表尚未开放，不能抽取；正数是倍率，不是目标数量或整局百分比。新等级刚解锁时权重较低，之后再提高；较低等级不会被强制关闭，避免后期四个目标都只能靠漫长准备推进。抽空的层只在当前合法集合中重新归一化，不借用未解锁等级或维度。

## 维度与获取方式仍独立生效

|预设|下界开始进度|末地开始进度|
|---|---:|---:|
|休闲|关闭|关闭|
|简单|50%|关闭|
|标准|25%|关闭|
|困难|25%|70%|
|噩梦|20%|65%|

因此进入下界、末地也需要先完成一定数量的目标。维度解锁不会强制抽到该维度，也不会立即开放尚未达到进度的高等级。

三个获取标签保留原有宏观倾向：

|完成进度|常规采集 GATHER|加工制作 CRAFT|探索获取 EXPLORE|
|---|---:|---:|---:|
|0%～不足 20%|45|40|15|
|20%～不足 80%|25|30|45|
|80% 起|30|40|30|

标签控制获取方式，不代表任务简单或快速；高成本加工物仍须等待其等级开放。顺序是**合法维度 → 当前阶段合法等级及动态权重 → 该层获取标签 → 具体 Material**。开局发育由 T1–T2 的硬限制保障，中期再提高探索倾向。

## 补位、重抽与 Racing

开局按完成数 0 填入最多四个目标。每次完成后，用新的已完成数进行补位；重抽也使用当下完成数。不会按“已生成到第几个”提前解锁，重抽不能绕过阶段门槛。已有目标保持有效，跨阶段不会自动替换。

继续保留去重、整组重抽、次数上限和原子提交。开局容量校验同时检查维度门槛和等级门槛，避免到下个阶段前无目标可抽。Racing 继续使用共享懒加载序列；两队不同补位时机、完成顺序不改变公平语义。没有固定简单槽、槽位反馈、装备检测或按领先情况调整难度。

## 自定义与本地文件

分级自定义使用相同默认阶段，只从玩家实际勾选的维度和等级抽取。开局必须选中足量的 T1/T2；只勾 T5/T6 而未给开局留下候选时会拒绝开始，不会偷偷加入未勾选的低级方块。

本地文件仍保持独立：方块、维度门槛、是否启用等级渐进均由 `custom/blocks.yml` 决定，不受 GUI 铜开关和分级选择限制。文件内新增可选 `tier-progression` 段，格式与预设相同，模板默认 `enabled: false`；管理员明确启用后才使用文件中的阶段规则。旧本地文件缺少该段时也保持关闭，不改变原有自定义意图。

## 配置与升级

五份 `presets/*.yml` 新增 `tier-progression`，每阶段设置 `start-percent` 和六项 `tier-multipliers`。阶段必须从 0% 开始、严格递增，已开放等级不能在之后重新锁定，最后阶段六级倍率均应为正值；玩家是否允许某一级仍由预设/勾选决定。

旧的磁盘预设缺少该段时，加载会补入默认规则并保存，已有权重和维度设置保留。`pacing.enabled` 只控制获取标签，`tier-progression.enabled` 单独控制等级阶段；关闭后者会恢复固定等级权重，仍受预设范围及维度门槛限制。

已经开始的比赛使用存档快照，不会在更新后擅自替换双方目标。旧 v2/v3 快照缺少等级阶段时，继续其原有序列；**本次新节奏从重新开始的一局生效**。新快照会保存完整阶段及生成规则标记，规则损坏时拒绝恢复，不用默认值悄悄改变比赛。

准备记分板同时兼容旧语言文件，将分开的“方块库”和 `%blocks%` 两行合并后显示，右侧仍连续编号，无需仅为此手工修改语言文件。

## 验证与体验边界

79 项自动化测试覆盖阶段取整、五预设共 500 组开局种子、两队补位和重抽、快照恢复、非法自定义拒绝，以及旧 v2 随机序列回归。

另以真实 Paper 26.3 注册表抽样 **1,000 局、50,000 个目标**，完整数据见[阶段抽样报告](progression-sampling.md)。在无重抽、铜附属关闭、每局 50 目标条件下，各阶段实际平均 T 级为：

|预设|发育|拓展|探索加工|进阶|收尾|
|---|---:|---:|---:|---:|---:|
|标准|1.48|1.87|2.49|2.75|2.85|
|困难|1.42|1.96|2.69|3.17|3.71|
|噩梦|1.52|2.02|2.78|3.36|4.18|

所有开局均无 T3–T6；T6 只在噩梦的 80% 后新生成。默认标准预设的探索标签由发育阶段约 7% 增至中后期约 28%～37%。这是实际候选库、阶段与维度权重共同作用的结果，并非配额或真实耗时承诺；对局时长仍需玩家实测调整。
