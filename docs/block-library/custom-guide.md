# 自定义方块设置

在“难度 / 方块库”中选择“自定义”即可使用已保存的设置。旁边的详细设置按钮打开编辑界面，不改变当前难度。

## 分级自定义

主世界、下界、末地各有独立开关。点击各维度的详细设置可勾选 T1–T6，每级显示可用数量及代表方块。修改自动保存到 `custom/settings.yml`；返回难度页选择自定义，或点击界面下方“使用分级自定义”启用。

维度解锁进度按本队已完成目标数计算。左键减 5%，右键加 5%，Shift 每次调整 10%，范围为 0%–100%。至少一个有候选的维度需要从 0% 开始。

分级自定义遵守[等级阶段](pacing-guide.md)：开局 T1–T2，15% 开放 T3，35% 开放 T4，60% 开放 T5，80% 开放 T6。勾选范围需要保留足量的开局低级方块，只选高等级时会拒绝开局，不会自动补入未勾选等级。

铜附属按钮与准备菜单保持同步，对标准预设和分级自定义生效。目标数量在准备菜单单独设置，默认每队 50 个。

## 本地文件模式

点击“使用本地自定义方块配置”读取：

```text
plugins/BlockRacing/custom/blocks.yml
```

文件独立决定方块列表和解锁进度，不受分级界面的维度开关、等级勾选、进度或铜附属开关影响。

```yaml
overworld:
  unlock-percent: 0
  tier-1:
    - minecraft:dirt
    - minecraft:cobblestone
  tier-2:
    - minecraft:glass
nether:
  unlock-percent: 50
  tier-1:
    - minecraft:netherrack
end:
  unlock-percent: 70
```

以上仅为格式示例，四个候选不足以开始默认 50 目标的对局。插件生成的[示例文件](../../src/main/resources/custom/blocks.yml)包含足够的候选，可在其基础上修改。

- 每个方块在整个文件中只可出现一次；省略的维度或等级视为空集合。
- 推荐使用 `minecraft:oak_log` 这样的标准 ID，也兼容可解析的旧枚举名。
- 只接受目录中已收录的生存方块；非法 ID、普通物品和创造专用方块会被拒绝。
- 可将收录方块放到自定义的维度和等级中；获取标签沿用原数据。
- `unlock-percent` 必须为 0–100 的整数，缺省为 0%。只有下界或末地候选时，应把首个可用维度设为 0%。
- 本地名单中明确列出的铜附属方块会保留，无论界面开关是否开启。
- 可选的 `tier-progression` 段控制本地等级阶段，格式与标准预设相同；默认及缺省均关闭，仅在文件明确启用后生效。

修改文件后，在准备阶段重新点击本地配置按钮即可读取和校验。重复、非法条目、容量不足或门槛前无可用目标会显示原因，失败时不会切换当前库。开局前也会重新校验。

`custom/settings.yml` 的 `source: tiers` 或 `source: local` 保存来源，`config.yml` 的 `difficulty: custom` 保存当前难度。切回标准预设不会删除自定义数据。

## 对局与更新

自定义继续使用四个当前目标、按需补位、整组重抽、去重及 Normal/Racing 规则。开局保存候选、门槛和权重快照，进行中编辑配置不改变本局任务。

更新前先停服并备份整个 `plugins/BlockRacing`，包括自定义文件、对局存档和对应世界；删除配置目录并重启生成新文件后，再按新格式合并设置，勿直接覆盖回旧配置或语言文件。
