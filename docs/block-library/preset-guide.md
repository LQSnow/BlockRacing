# 难度预设与铜附属开关

准备菜单提供休闲、简单、标准、困难、噩梦和自定义六个单选项。默认标准难度、每队 50 个目标；目标数量独立设置。

## 范围与维度门槛

|预设|配置 ID|主世界|下界|末地|下界门槛|末地门槛|
|---|---|---|---|---|---:|---:|
|休闲|casual|T1–T2|关闭|关闭|—|—|
|简单|easy|T1–T2|T1–T2|关闭|50%|—|
|标准|normal|T1–T4|T1–T3|关闭|25%|—|
|困难|hard|T1–T5|T1–T5|T1–T5|25%|70%|
|噩梦|nightmare|T1–T6|T1–T6|T1–T6|20%|65%|

门槛使用本队已完成目标数，按 `ceil(total * percent / 100)` 计算。50 目标时，简单的下界门槛是完成 25 个，困难的末地门槛是完成 35 个。解锁表示获得抽取资格，不保证立即出现该维度。

等级也按进度开放：开局 T1–T2，15% 开放 T3，35% 开放 T4，60% 开放 T5，80% 开放 T6。实际范围取等级阶段、维度门槛和预设范围的交集；重抽遵守同样规则。详见[阶段节奏](pacing-guide.md)。噩梦仍只包含方块，不包含工具、食物等普通物品。

## 铜附属开关

开关对五个标准预设和分级自定义生效。本地文件模式完全使用文件中的名单，不受该开关控制。

- 基础铜矿、粗铜块、铜块及普通未氧化、未涂蜡铜制品保留，仍须符合所选预设的等级范围。
- 氧化、涂蜡变种及铜傀儡雕像受开关控制，默认关闭。
- 开启不会提前解锁等级、维度或扩大预设范围。

|预设|铜附属关闭时的候选数|开启时的候选数|
|---|---:|---:|
|休闲|242|242|
|简单|252|252|
|标准|857|931|
|困难|975|1,067|
|噩梦|988|1,094|

候选数表示整个预设的容量，不表示当前进度可抽数量或各类概率。容量不足时应降低本局目标数或调整选择。

## 配置

```yaml
difficulty: normal
copper-extras: false
block-amount: 50
```

标准预设位于 `presets/{casual,easy,normal,hard,nightmare}.yml`：

- `max-tiers`：主世界、下界、末地的等级上限，标准预设边界固定。
- `unlock-percent`：三个维度开始出现的已完成进度百分比。
- `tier-weights`：T1–T6 的基础权重。
- `dimension-weights`：主世界、下界、末地的权重。
- `tier-progression`：各阶段等级门槛及权重倍率。
- `pacing`：采集、加工、探索三类获取方式的阶段权重。

只在已启用、已解锁且有候选的集合中抽取；空集合会跳过并重新归一化。权重不等于固定任务配额。

菜单设置会保存。准备阶段修改磁盘预设后，执行 `/debug reload` 或重启。已开始的比赛使用开局快照，不受后来配置修改影响。

每队同时最多四个当前目标，完成一个才补入新目标。重抽需要队伍投票，菜单显示剩余次数；候选不足时不替换、不扣次数。Normal 两队独立抽取，Racing 使用公平的共享基础序列。
